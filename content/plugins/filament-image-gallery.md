**Filament Image Gallery** is a flexible and lightweight plugin that allows you to display
multiple images in a clean, interactive gallery with a built-in image viewer.

It is designed to integrate seamlessly with Filament and provide a consistent user experience
across different UI contexts.

### Features
- Display image galleries inside **Table Columns**
- Use galleries within **Infolist Entries**
- Render galleries using a reusable **Blade Component**
- Built-in image viewer with navigation
- Clean and customizable UI
- Supports **Filament v3 & v4**

### Use Cases
- Admin panels with multiple image previews
- Product galleries
- Media management interfaces
- Read-only or interactive image displays

The plugin is easy to install, simple to configure, and optimized for performance in large datasets.
